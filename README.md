# Змейка — Android-проект

Игра лежит в app/src/main/assets/index.html, обёртка — WebView в MainActivity.java.

## Где взять APK
Каждый push автоматически собирает APK (вкладка Actions → Build APK, ~3 мин).
Готовый файл snake.apk появляется во вкладке **Releases**.

## Сборка в Android Studio
File → Open → эта папка → Build → Build APK(s).

На телефоне разрешите установку из неизвестных источников.
